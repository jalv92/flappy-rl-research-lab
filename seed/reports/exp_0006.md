# Experiment 6: H005 — Drawing exploratory actions from a survivor action prior instead of uniformly

- Stage: **confirmation** (confirmatory) · profile `final_confirmation` · code `4122139` · variant source `5655f260e945`
- Decision: **confirmed**
- Conclusion: significantly better on auc with fresh seeds. auc: diff +0.167 (95% CI +0.103..+0.229, P(improve)=0.95); final_mean: diff +7.6 (95% CI -74.8..+88.2, P(improve)=0.47)

## Hypothesis
- Area: exploration
- Motivation: A uniform random action flaps 50% of the time, which ends the episode at the ceiling within a few ticks; almost all early experience is the same uninformative crash.
- Modification: Epsilon-greedy's random actions use the flap frequency observed in the agent's own longer-than-median episodes (starts at 0.5, i.e. identical to the control).
- Expected benefit: Longer early episodes, earlier first obstacle clears, higher AUC.
- Failure modes considered: The prior can lock onto a degenerate frequency; less state coverage near the ceiling.
- Prior work: Related: action priors; temporally-extended exploration (ez-greedy, Dabney et al. 2021).
- Novelty status: unverified
- Baseline: xdqn control: identical hyperparameters, step budget, seeds and evaluation schedule
- Criteria: Primary: validation AUC (sample efficiency) and final-policy validation mean, per training seed, candidate vs control. Promising only if a 95% bootstrap CI of the difference excludes 0 in the favourable direction and no primary metric is significantly worse. Secondary: degradation count, seed CV, wall-clock ratio.
